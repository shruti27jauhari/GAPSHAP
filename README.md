## Setup Instructions

To run this app, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [repository URL]
    cd chatu
    ```
2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
3.  **Configure Supabase:**
    *   Create a Supabase project at [supabase.com](https://supabase.com).
    *   Update `lib/main.dart` with your Supabase URL and anon key.
    *   Enable the `pg_cron` extension in your Supabase project.
    *   Set up Row Level Security (RLS) policies as described in the documentation.
    *   Configure Supabase Storage and add the necessary RLS policies.
4.  **Run the app:**
    ```bash
    flutter run
    ```
